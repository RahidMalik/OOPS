## SECTION 1: JAVASCRIPT KYA HAI ?

### Simple Definition:

"Javascript ek asi language ha jo website ka engine hota ha. html website ka strucutre tyar krta ha, css website ka design banata ha, javascript ya tay krta ha ka as button or kia ho ga, form submit pr kia krna ha, sab ko javascript he control krta hai."

### Real Life Analogy:

- HTML = Ghar ka structure (walls, doors, windows, roof)
- CSS = Ghar ka design (color, furniture, wallpaper, decoration)
- JavaScript = Ghar ke electricity, lights, fan, AC (jo on/off hota hai, user interact karta hai)

### Where JavaScript Runs:

- Browser (Chrome, Firefox, Safari, Edge) - Sabse common
- Node.js - Server pe bhi JS chalta hai
- Deno - Node.js ka alternative
- React Native / Electron - Mobile apps aur desktop apps banane ke liye

### History:

- 1995: Brendan Eich ne 10 din mein JavaScript banaya
- Pehle naam tha Mocha, phir LiveScript, phir JavaScript (marketing trick)
- Ab JavaScript sabse zyada use hota hai programming language mein

### Key Characteristics:

- Interpreted language: Line by line chalta hai, pehle compile nahi hota
- Single-threaded: Ek baar mein ek hi kaam kar sakta hai
- Dynamically typed: Variable ka type fix nahi hota, runtime par decide hota hai
- Object-oriented: Objects ke basis par kaam karta hai
- Prototype-based: Classes nahi, prototypes use karta hai inheritance ke liye

### JavaScript vs Java:

- JavaScript: Web development ke liye, interpreted, prototype-based
- Java: Enterprise apps, compiled, class-based
- Similarity: Sirf naam mein, logic mein koi relation nahi
